Trust / Privacy

Privacy notice

AI Notetaker is designed to keep meeting data under your control. This notice explains what the public website does and how the app handles information in its local, self-hosted, and future managed modes.

Effective date: September 29, 2026

The project-operated Hosted AI service is not yet available. The managed-mode details below describe the product architecture and will be updated before that service accepts users.

1. The public website

This is a static website hosted by GitHub Pages. It does not provide a sign-in form, accept meeting files, run advertising, or include analytics or tracking scripts. Its icons and styles are served from this site.

The home page requests the public release manifest from GitHub so it can show current downloads, checksums, and the available extension install link. Your browser also contacts GitHub or other sites when you follow links to releases, documentation, the Chrome Web Store, or contributor resources. GitHub and those services process requests under their own privacy terms. GitHub Pages may process standard connection and request information to deliver and protect this website.

2. Meeting data in local mode

When you record, the app captures microphone and meeting audio. It saves raw audio on your device before making a provider request. The microphone and remote/system audio are kept as separate tracks. Transcripts, summaries, action items, settings, provider keys, and retry information are stored locally as described in the data-handling guide.

  • Your AI provider keys are stored in protected local extension storage. The project does not receive those keys in local mode.
  • Audio and related text are sent directly to the transcription or summarization provider you configure when needed to process a meeting. That provider's privacy policy and retention terms apply.
  • The project does not receive local-mode recordings, transcripts, or notes unless you separately choose to export, sync, or share them using another service.
  • Google Drive export and self-hosted history are optional destinations you choose. Their operators receive the data you send there.
  • Local BYOK mode does not send telemetry or error reports to the project.

3. Self-hosted history

If you configure the optional webapp, selected notes or recordings are sent to the server you chose. The server operator controls access, storage, backups, retention, logs, and deletion. When you operate that server, you are responsible for its configuration and for meeting any privacy obligations that apply to you.

4. Future project-operated hosted mode

The project-operated paid mode is being prepared but is not open for sign-up or production use. In its planned design, audio is saved locally first, then authenticated uploads and resulting notes are processed and stored in a workspace managed by the service. Provider credentials remain on the server and are not delivered to the extension. If configured for the service, operational error monitoring may process technical diagnostics; client error records are sent only while signed in to Hosted AI. We will publish service-specific collection, retention, deletion, subprocessors, and contact details before opening this mode.

5. Deletion and retention

You can delete meetings and recordings from the app. Local data is stored on your device; removing the browser extension alone does not delete helper files, provider account data, exported files, or data in a separately configured server. Delete synced or exported data from each destination as well. The data-handling guide explains the current deletion paths. Provider retention is governed by the provider you choose.

6. Meeting participants

You control when capture starts and stops. Tell participants and obtain consent where required by law, workplace policy, or your agreements. The app's reminder is not a substitute for consent or legal advice.

7. Security and changes

The source code and security reporting instructions are public. Please use the security policy to report a suspected vulnerability privately; do not include meeting content or credentials in a public issue. This notice may change as the software and services change. The effective date above indicates the latest revision.

8. Contact

For questions about the open-source app or this notice, use the project's GitHub issue tracker. Never post API keys, recordings, transcripts, or other sensitive meeting data in a public issue.

This notice is a plain-language description of current product behavior, not legal advice.
