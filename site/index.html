AI Notetaker

Start taking notes without a meeting bot.

Take Google Meet notes in Chrome with your own API keys (free) or optional Hosted AI (paid). For Zoom, Teams, Slack, and other desktop calls, add the desktop helper.

1. Start with Google Meet

Install the Chrome extension, finish setup, then open a Meet call and choose Start notes from the extension. Using your own API keys requires no desktop helper or account.

2. Add desktop-call capture (optional)

Choose this path only if you want to record Zoom, Teams, Slack, or another desktop call. The helper captures your microphone and system audio locally.

Optional: self-host history with Docker

Use Docker Compose for the authenticated webapp and Postgres. It never receives your provider keys and cannot replace the desktop helper.

Audio drivers are only needed for desktop-call capture. macOS users install BlackHole from Existential Audio when the helper selects that fallback; Windows uses base VB-CABLE when native loopback is unavailable; Linux uses the helper's PulseAudio/PipeWire modules.
